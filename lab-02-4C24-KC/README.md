# Laboratorio 02 - Control de Versiones con Git y GitHub

## Descripción
Este proyecto corresponde al desarrollo del **Laboratorio 02** de la asignatura **Construcción y Pruebas de Software**. En esta práctica se aplican conceptos de control de versiones, flujos de trabajo con Git, uso de `.gitignore` para la exclusión de archivos temporales y sincronización entre repositorios locales y remotos.

## Datos del Estudiante
* **Estudiante:** Karla Estefany
* **Curso:** Construcción y Pruebas de Software
* **Sección:** 4C24

## Contenido del Laboratorio
1. **Inicialización y Configuración:** Creación del repositorio local y vinculación con GitHub.
2. **Uso de `.gitignore`:** Exclusión de archivos temporales (`*.tmp`).
3. **Flujo de Trabajo Clonado:** Simulación de trabajo en entornos secundarios (`git clone`, `git pull`).

## Tecnologías Utilizadas
* **Git:** Sistema de control de versiones distribuido.
* **GitHub:** Plataforma de alojamiento de código.
* **Git Bash / PowerShell:** Interfaz de consola.
